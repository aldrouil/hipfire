## Purpose

Native BF16 and quantized HFQM loading, multi-loop normalized-GPT forward, and
GPU-state ownership for Nemotron Dory. See [`src/lib.rs`](src/lib.rs) for the execution contract.

## Gotchas

- Runs input/output blocks once and the shared recurrent block 1–4 times; resolves the checkpoint loop count and cache mode before allocation.
- `per_loop` allocates independent recurrent histories; `last_loop` overwrites only current-token rows and retains final-loop history for prior tokens. Tokenwise prefill preserves that ordering.
- Weights retain their encoded precision; activations are F32. KV is `auto`/Q8 or FWHT2/3/4 K with Q8 V; F32 KV is an internal oracle reference only. Size `max_seq` explicitly for available VRAM.
- HFQM admits MQ3/4/5/6V2, MQ8 and Q8. Dory MQ2V2 is deliberately refused.
- Speculation, offload, and multi-GPU execution are not supported.
- Deprecated asym/turbo KV names and native FP8/BF16/F16 cache presets are refused.
- Packed sliding-window views use codec byte strides and a relative attention position; RoPE remains absolute.
